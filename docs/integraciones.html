Facebook / Meta Pixel ✓ Activo
Seguimiento del lado del navegador — rastrea visitantes y eventos
ℹ️

¿Qué es el Pixel?

Un fragmento de JavaScript que Meta instala en el navegador del visitante. Registra PageViews, ViewContent, Contact y Search. Alimenta las campañas de Facebook e Instagram con datos reales de comportamiento.

📍 Dónde encontrar tu Pixel ID

1

Ir al administrador de anuncios correcto

Abre adsmanager.facebook.com con la cuenta que creó el Pixel.

⚠️

Si tienes varias cuentas de Facebook, asegúrate de estar logueado con la que creó el Pixel. No aparecerá si estás en la cuenta equivocada.

2

Ir a Events Manager

Menú principal → Todos los instrumentos → Events Manager

🔗 https://business.facebook.com/events_manager2/list/pixel
3

Seleccionar el conjunto de datos correcto

Busca el que tenga el ícono de Píxel de Meta (no "App" ni "Offline"). Anota el ID numérico de 15-16 dígitos.

⚡ Eventos que dispara automáticamente

EventoCuándo se disparaDatos enviados
PageViewAl cargar cualquier páginaURL, referrer
ViewContentAl abrir la tarjeta de un ítemID, título, precio, tipo
ContactAl enviar consulta (WhatsApp, llamada, form)Canal, propiedad
SearchAl usar filtros de búsquedaTexto buscado, filtros

🔧 Flujo de inyección en el sitio

Admin guarda Pixel ID
→
settings.json
→
/tracking.js (dinámico)
→
index.html defer
→
fbq('init') en navegador

El endpoint /tracking.js se sirve con Cache-Control: no-store — los cambios del admin toman efecto inmediato sin deploy.

Meta Conversions API (CAPI) ✓ Activo
Seguimiento servidor-a-servidor — funciona aunque el navegador bloquee el Pixel
🛡️

¿Por qué es fundamental tener CAPI además del Pixel?

iOS 14+, Safari y los bloqueadores de anuncios bloquean el Pixel del navegador. CAPI envía los mismos eventos directamente desde el servidor a Meta. Resultado: capturas el 20–40% adicional de conversiones que el Pixel solo perdería.

🔑 Cómo generar el token de acceso

1

Ir a Events Manager → tu Pixel

🔗 https://business.facebook.com/events_manager2/list/pixel

Haz click en tu conjunto de datos (el que tiene el ícono de Pixel de Meta).

2

Pestaña "Configuración"

Haz click en la pestaña Configuración en el menú superior del dataset.

3

Sección "API de conversiones" → Generar token

Baja hasta "API de conversiones" → selecciona "Configurar con Dataset Quality API (Recommended)" → "Generar token de acceso".

El token empieza con EAA… y tiene ~200 caracteres. Cópialo completo.

4

Guardarlo en el servidor (.env)

En la consola del VPS (sin TTY) usa sed, no nano:

sed -i "s|FB_ACCESS_TOKEN=.*|FB_ACCESS_TOKEN=EAA_TU_TOKEN|" /var/www/tu-proyecto/.env
pm2 restart all
⚠️

nano no funciona en consolas web de hosting (requiere TTY). Siempre usar sed -i para editar el .env desde esa consola.

🐛 Errores comunes

🔴 Error #190 — Invalid OAuth access token

Causa: El token venció. Los tokens de perfil personal duran ~60 días y expiran automáticamente.

Síntoma: Columna CAPI muestra "Invalid OAuth access token - Cannot parse access token [190]"

✅ Solución Genera un nuevo token en Events Manager → Configuración → API de conversiones. Actualiza el .env con sed y reinicia PM2.

🔴 Error #100 — Missing Permission

Causa: El token no tiene permiso ads_read para leer metadata del Pixel. Ocurre al intentar verificar el token con un GET a la Graph API en lugar de solo enviar eventos.

Importante: Este error en verificación no significa que el CAPI no funcione. Un token puede enviar eventos correctamente y aún fallar una lectura de metadata.

✅ Solución Si los eventos muestran "✓ recibido" en el Debug Pixel, el token funciona correctamente. El error #100 solo aplica a consultas de metadatos, no al envío de eventos.
♾️

Token permanente — recomendado para producción

Para evitar renovar el token cada 60 días, crea un System User Token desde Meta Business Settings → System Users:

  • Crea un System User con rol Admin
  • Click "Generar nuevo token" → otorga permisos ads_management y business_management
  • Este token nunca vence a menos que lo revoques manualmente

Catálogo de Facebook Ads
Feed automático de productos para anuncios dinámicos de retargeting
💡

¿Para qué sirve?

Permite crear anuncios dinámicos que muestran automáticamente el producto exacto que alguien visitó. Meta sincroniza el feed cada hora y retargetea con ese ítem específico en Instagram y Facebook.

📡 URL del feed generada automáticamente

📄 https://tu-sitio.com/api/feed/facebook.csv

Se actualiza en tiempo real con cada cambio de productos. No requiere mantenimiento.

⚠️ Error crítico — NO crear catálogo tipo "Real Estate" o "Bienes raíces"

🔴 Problema con el tipo de catálogo "Bienes raíces"

Meta exige campos ultra-específicos del schema de Real Estate que son muy difíciles de cumplir desde un CSV externo:

  • Requiere home_listing_id en lugar de id
  • Requiere listing_type con valores exactos (for_rent, for_sale)
  • Requiere availability con valores (for_rent, recently_sold, etc.)
  • Los errores de validación son crípticos y el feed completo se rechaza si un campo falla
  • Soporte limitado en Advantage+ Catalog Ads vs. catálogo de Productos
✅ Solución: Crear como "E-commerce / Productos online" El feed CSV ya genera los campos en formato de Catálogo de Productos. Meta lo acepta sin problemas, permite Dynamic Ads idénticos y tiene soporte completo en Advantage+ Catalog Ads.

📋 Pasos para crear el catálogo correctamente

1

Ir a Commerce Manager

🔗 https://business.facebook.com/commerce/
2

Crear catálogo → tipo "E-commerce"

Click "Crear catálogo" → selecciona "E-commerce" → NO selecciones "Bienes raíces". Dale un nombre descriptivo.

3

Agregar fuente de datos → URL del feed

"Orígenes de datos" → "Agregar artículos" → "Usar una fuente de datos" → "Lista de datos programada"

Pega la URL del feed CSV. Frecuencia: Cada hora.

4

Vincular el catálogo al Pixel

"Configuración" → "Orígenes de eventos" → conecta tu Pixel ID. Esto activa el retargeting automático.

5

Crear campaña

Ads Manager → Crear campaña → Objetivo: "Ventas" → Conversión: "Catálogo" → selecciona tu catálogo.

Google Tag Manager ✓ Activo
Container: GTM-XXXXXXX — Gestor central de todos los tags de marketing
🎯

¿Qué ventaja da GTM?

Con GTM activo puedes agregar o modificar cualquier tag de marketing (GA4, TikTok Pixel, Clarity, Google Ads…) desde la interfaz web de Google sin tocar el código ni hacer deploy. Los cambios toman efecto en segundos.

📍 Dónde encontrar tu Container ID

🔗 https://tagmanager.google.com

El Container ID tiene el formato GTM-XXXXXXX — aparece en la esquina superior derecha de tu workspace.

➕ Cómo agregar tags sin código

1

Abrir GTM → tu contenedor

Ve a tagmanager.google.com → selecciona tu workspace.

2

Crear nueva etiqueta

Menú izquierdo → Etiquetas → Nueva. Elige el tipo predefinido (GA4, Ads) o usa "HTML personalizado" para cualquier otro.

3

Configurar activador → All Pages

En "Activación" selecciona All Pages para que cargue en todas las páginas del sitio.

4

Publicar

Click "Enviar" → nombra la versión → "Publicar". Cambios en producción en segundos.

📊 GA4 via GTM

Tipo: Google Analytics: GA4. Ingresa tu Measurement ID (G-XXXXXXXXXX). Activador: All Pages.

🎥 Clarity via GTM

Tipo: HTML personalizado. Pega el snippet de clarity.microsoft.com. Activador: All Pages.

🎵 TikTok Pixel via GTM

Tipo: HTML personalizado. Snippet en ads.tiktok.com → Biblioteca → Pixel.

Google Analytics 4 ⏳ Pendiente
Análisis de tráfico total, comportamiento y conversiones
⚠️

¿Por qué es importante junto al Pixel de Meta?

Meta Pixel solo ve el tráfico que viene de Meta. GA4 ve todo el tráfico: orgánico, directo, Google Ads, referidos. Sin GA4 no sabes cuánto tráfico viene de Google ni qué páginas tienen más rebote.

📋 Pasos para crear y conectar GA4

1

Crear propiedad GA4

🔗 https://analytics.google.com

Click "Crear propiedad" → nombre del proyecto → zona horaria → moneda local.

2

Crear flujo de datos web

"Flujos de datos" → "Agregar flujo" → "Web" → ingresa la URL del sitio. Se genera un Measurement ID tipo G-XXXXXXXXXX.

3

Instalar via GTM (recomendado)

GTM → Nueva etiqueta → tipo "Google Analytics: configuración de GA4" → pega el Measurement ID → Activador: All Pages → Publicar.

4

Verificar en tiempo real

GA4 → "En tiempo real". Abre el sitio en otra pestaña → deberías ver 1 usuario activo.

🌐 Tráfico orgánico

Cuánta gente llega desde Google de manera orgánica (SEO).

📱 Dispositivos

% móvil vs desktop, duración de sesión promedio.

📍 Geografía

De qué ciudades y países llegan los visitantes.

🔄 Embudos

Visitantes → ven producto → hacen contacto. Tasa de conversión real.

Google Search Console ⏳ Pendiente
SEO — Muestra con qué palabras encuentran el sitio en Google
🔑

¿Qué hace Search Console?

Muestra exactamente qué búsquedas llevan tráfico al sitio, en qué posición aparece, cuántos clics recibe, y si hay errores de indexación. Gratis y esencial para SEO.

📋 Registro paso a paso

1

Registrar la propiedad

🔗 https://search.google.com/search-console

Click "Agregar propiedad" → tipo "Prefijo de URL" → ingresa https://tu-sitio.com

2

Verificar via GTM (más fácil)

Google genera una <meta> tag de verificación. En GTM → nueva etiqueta → HTML personalizado → pega la meta tag → All Pages → Publicar. Luego en Search Console → verificar.

3

Enviar sitemap

Search Console → "Sitemaps" → ingresa sitemap.xml. Acelera la indexación de contenido nuevo.

Microsoft Clarity ✓ Activo
Grabaciones de sesión en tiempo real y mapas de calor — 100% gratis
💡

Lo que Clarity registra

Cada visita queda grabada como un video. Ves exactamente cómo navegó el usuario, qué tocó, dónde se confundió. También genera mapas de calor mostrando qué zonas reciben más clics.

📍 Dónde ver los datos

🔗 https://clarity.microsoft.com/projects/view/TU_CLARITY_ID

Los primeros registros aparecen ~2 horas después de instalar. Las grabaciones se conservan 90 días.

🔧 Snippet de instalación

Pega en Admin → Integraciones → Marketing → "Código personalizado". Se inyecta en todas las páginas vía /tracking.js.

<script type="text/javascript">
  (function(c,l,a,r,i,t,y){
    c[a]=c[a]||function(){(c[a].q=c[a].q||[]).push(arguments)};
    t=l.createElement(r);t.async=1;t.src="https://www.clarity.ms/tag/"+i;
    y=l.getElementsByTagName(r)[0];y.parentNode.insertBefore(t,y);
  })(window, document, "clarity", "script", "TU_CLARITY_ID");
</script>

📊 Métricas clave a monitorear

😤 Dead clicks

Clics en elementos que no hacen nada — indica confusión del usuario.

😡 Rage clicks

Varios clics rápidos — el usuario espera una respuesta que no llega.

📜 Scroll depth

Hasta dónde bajan antes de irse. Identifica dónde se pierde la atención.

🚪 Exit pages

En qué punto exacto abandona el sitio la mayoría de visitantes.

UTM Tracking ✓ Activo
Atribución de leads por fuente — Instagram, Facebook, Google, etc.
📌

¿Qué son los parámetros UTM?

Se agregan a la URL del sitio para saber exactamente de dónde viene cada visitante. El sistema los detecta automáticamente y los asocia a cada lead registrado.

🔗 Formato de URL con UTM

📎 https://tu-sitio.com/?utm_source=instagram&utm_medium=bio&utm_campaign=nombre-campaña
Parámetro¿Qué indica?Valores comunes
utm_sourcePlataforma de origeninstagram, facebook, google, tiktok, email
utm_mediumTipo de mediobio, story, paid, organic, cpc, email
utm_campaignNombre de la campañalanzamiento, retargeting, mayo2026
utm_contentVariante del anunciovideo1, imagen-hero, carrusel (opcional)

⚙️ Flujo interno

Visitante llega con ?utm_source=…
→
app.js guarda en sessionStorage
→
Lead incluye UTMs
→
leads.db los almacena
→
Admin → Audiencia → tabla UTM
🛠

Herramienta para crear UTMs sin errores

Usa el Google Campaign URL Builder para generar URLs con UTMs correctamente formateados.
